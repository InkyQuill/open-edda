# Open Edda agent instructions

Before designing, implementing or reviewing any interface change, read [DESIGN.md](DESIGN.md). Treat its approved rules as the visual source of truth, especially Galley Themes, Thoth defaults and the borderless Galley Editor integration.

Read [PRODUCT.md](PRODUCT.md) for confirmed audience, purpose and product constraints. Impeccable workflow defaults live in `.impeccable/config.json`; keep them separate from product and visual rules.

Read [CONTEXT.md](CONTEXT.md) for product terminology and [README.md](README.md) for project setup and verification commands.

User instructions take precedence. Update DESIGN.md when the author approves a change to the design system so subsequent runs use the same decisions.
